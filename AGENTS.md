# Antigravity Matt Pocock Skills Plugin

Project repository for packaging and maintaining Matt Pocock's skills as a Google Antigravity plugin.

## Common Commands

- **Sync Upstream**: `./scripts/sync.sh`
- **Validate Skills**: `./scripts/validate.sh`
- **Test Auto-Updater Hook**: `echo '{"conversationId":"test"}' | ./scripts/auto-update.sh`
- **Install/Update Locally**: `./install.sh`
